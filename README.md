# OH & NOH · Luna di Miele 2027

2027년 1월 18일 ~ 27일 이탈리아 신혼여행 앱
(코모 → 밀라노 → 베네치아 → 피렌체 → 로마)

- **일정**: 날짜별 코스, 기차표, 숙소
- **예약**: 예약 순서, 체크리스트 (박물관 · 기차 · 숙소 · 짐 보관 · 식당)
- **이동**: 기차 · 버스 정보, 이탈로 운임 비교
- **맛집**: 도시별 추천 식당

## 파일 구성

| 파일 | 역할 |
|---|---|
| `index.html` | 앱 본체 |
| `manifest.webmanifest` | 홈 화면 앱 이름 · 아이콘 설정 |
| `sw.js` | 인터넷이 없어도 앱이 열리게 하는 파일 |
| `icons/` | 앱 아이콘 (OH & NOH 이미지) |
| `.nojekyll` | GitHub Pages 설정용 빈 파일 (지우지 마세요) |

## GitHub Pages에 올리는 방법

1. GitHub에서 **New repository**를 만들어요. 이름은 추측하기 어려운 것으로 정하세요 (예: `ohnoh-2027-trip`).
2. **Add file → Upload files**를 누르고, 압축을 푼 폴더 안의 파일과 `icons` 폴더를 전부 끌어다 놓은 뒤 **Commit changes**를 눌러요.
   - `.nojekyll`은 숨김 파일이라 안 보일 수 있어요. 없어도 앱은 동작해요.
3. 저장소의 **Settings → Pages**로 가서 **Branch: `main` / `(root)`**를 선택하고 **Save**를 눌러요.
4. 1~2분 뒤 `https://아이디.github.io/저장소이름/` 주소로 앱이 열려요.

## 휴대폰에 앱으로 설치하기

- **아이폰**: 사파리로 주소를 열고 → 공유 버튼 → **홈 화면에 추가**
- **갤럭시**: 크롬으로 주소를 열고 → 메뉴(⋮) → **앱 설치** 또는 **홈 화면에 추가**

한 번 열어 두면 **인터넷이 없어도** 앱이 열려요.

## 알아둘 점

- 체크리스트 체크 내용은 **각 휴대폰에만 저장**돼요. 두 분이 따로 체크하면 서로 공유되지 않아요.
- 무료 GitHub Pages는 **주소를 아는 사람은 누구나 볼 수 있어요.** 숙소 주소와 날짜가 들어 있으니 주소를 널리 공유하지 마세요. 검색엔진에는 노출되지 않도록 설정해 두었어요.
- 티켓 코드, 여권 정보 같은 민감한 정보는 앱에 넣지 마세요.

## 내용을 수정했을 때

1. 새 `index.html`을 같은 방법으로 업로드해서 덮어써요.
2. `sw.js` 맨 위의 `oh-noh-v1`을 `oh-noh-v2`처럼 숫자를 하나 올려 저장해요.
3. 휴대폰에서 앱을 두 번쯤 다시 열면 새 내용으로 바뀌어요.
